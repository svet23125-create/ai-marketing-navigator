# AI Marketing Navigator

AI Marketing Navigator — учебный консольный RAG-ассистент о применении искусственного интеллекта в маркетинге бизнеса. Он ищет релевантные фрагменты в небольшой Markdown-базе знаний и формирует ответ на русском языке с помощью OpenAI API.

Это учебный консольный прототип, а не развёрнутый веб-сервис. Для работы нужен собственный API-ключ OpenAI; расходы на API зависят от использования аккаунта.

## Возможности

- Загружает Markdown-файлы из `assistant_api/data/public_demo/`.
- Разбивает материалы на чанки размером около 500 символов с перекрытием около 100 символов; учитывает заголовки, абзацы и предложения.
- Создаёт embeddings через `text-embedding-3-small` и хранит чанки в локальной ChromaDB.
- Находит до трёх наиболее близких фрагментов и передаёт их вместе с вопросом модели.
- Использует `gpt-6-luna` через OpenAI Chat Completions API.
- Добавляет к ответу названия файлов-источников. Если в найденном контексте нет достаточной информации, ассистент должен сообщить об этом и не выдумывать факты, числа или результаты кампаний.
- Кэширует ответы и использованные фрагменты в SQLite. Версия корпуса включена в имя коллекции и ключ кэша, поэтому изменение содержимого или имён Markdown-файлов приводит к использованию новой коллекции и не возвращает старые ответы.

## Как устроен RAG

1. При запуске приложение перечисляет `.md`-файлы непосредственно в `assistant_api/data/public_demo/`. Другие папки, вложенные каталоги и `docs.txt` загрузчик не обходит.
2. Каждый документ разделяется на смысловые фрагменты. Имя исходного файла сохраняется в метаданных каждого чанка.
3. Для чанков и вопроса создаются embeddings `text-embedding-3-small`. ChromaDB выполняет векторный поиск по косинусному расстоянию.
4. Найденные фрагменты с именами источников становятся контекстом для `gpt-6-luna`. Ответ и контекст записываются в SQLite-кэш.

Локальные данные создаются в `assistant_api/.local/`: там находятся ChromaDB и SQLite-кэш. Эта папка исключена из Git.

## Публичная демонстрационная база

В `assistant_api/data/public_demo/` находятся четыре подготовленных документа:

| Файл | Тема |
| --- | --- |
| `01_ai_marketing.md` | Основные применения ИИ в маркетинге, пример для малого бизнеса и ограничения. |
| `02_audience_analysis.md` | Анализ целевой аудитории, возможные источники данных и условные сегменты покупателей. |
| `03_content_creation.md` | Подготовка текстового и визуального контента с помощью генеративного ИИ и проверка материалов. |
| `04_marketing_strategy.md` | Планирование маркетинга, гипотезы и оценка фактических результатов кампаний. |

Примеры вопросов для ручной проверки:

- Как ИИ может помочь проанализировать целевую аудиторию мебельного магазина?
- Какие задачи ИИ может выполнять при подготовке контента для салона красоты?
- Сколько стоит разработка AI-маркетинговой стратегии?

Для третьего вопроса в демонстрационных материалах нет цены: ожидается, что ассистент прямо сообщит о нехватке информации, а не придумает сумму.

## Технологии

- Python 3.13.15 — версия окружения, на которой подготовлены зависимости проекта.
- OpenAI Python SDK `3.35.1` — генерация ответов и embeddings через OpenAI API.
- ChromaDB `1.5.9` — локальное векторное хранилище.
- `python-dotenv` `1.2.4` — чтение локального `.env`.
- SQLite из стандартной библиотеки Python — кэш вопросов, ответов и контекста.

Полный фиксированный список runtime-зависимостей и их версий находится в `assistant_api/requirements.txt`. RAGAS и зависимости ветки GigaChat для запуска консольного приложения не нужны.

## Установка и запуск

Команды ниже предназначены для PowerShell в корне проекта. Нужен установленный Python 3.13; для воспроизведения подготовленной среды используйте Python 3.13.15.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r assistant_api/requirements.txt
```

Создайте корневой `.env` из шаблона, если его ещё нет, и добавьте свой API-ключ:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

В `.env` должна быть задана переменная:

```dotenv
OPENAI_API_KEY=your-openai-api-key
```

Не публикуйте `.env` и не вставляйте реальный ключ в исходный код или README. `.env.example` содержит только безопасный шаблон.

Запустите приложение из корня проекта:

```powershell
python assistant_api/app.py
```

При первом запуске приложение создаст embeddings и локальный индекс ChromaDB, если индекс текущей версии базы ещё не существует. Для этого потребуется доступ к OpenAI API. Вводите вопросы в консоли; `stats` показывает статистику, `clear` очищает SQLite-кэш после подтверждения, `exit` завершает работу.

Путь к Markdown-базе и локальному хранилищу вычисляется от расположения файлов проекта. Если корневой `.env` существует, приложение загружает его по абсолютному пути; предусмотренный кодом резервный поиск `.env` использует текущую рабочую папку.

## Проверка проекта

По результатам ручного тестирования в PyCharm, о котором сообщил пользователь: в ChromaDB были загружены четыре Markdown-документа и 16 чанков; ответ об анализе целевой аудитории содержал источники; на вопрос о стоимости AI-стратегии ассистент не стал придумывать цену; повторный запрос был обслужен из SQLite-кэша.
